# Ficha para portafolio

**Nombre:** Chat grupal en tiempo real.
**Modalidad:** proyecto individual.
**Autor:** Sebastian Monga.
**Tecnologías:** Java, Spring Boot, React, WebSockets, STOMP y SockJS.

## Presentación propuesta

Aplicación web de mensajería grupal con actualización de mensajes y presencia en tiempo
real. Desarrollé el cliente React y el backend Spring Boot, con comunicación bidireccional
mediante WebSockets/STOMP.

## Qué mostrar en el paso 3

Dos usuarios conversando, un alias duplicado rechazado y la actualización de presencia
al cerrar una pestaña. Mostrar también la configuración necesaria para ejecutarlo.

## Límites que deben mantenerse visibles

Sin autenticación, persistencia ni múltiples salas. Despliegue público y grabación
pendientes. No se asignó una licencia de distribución nueva.
